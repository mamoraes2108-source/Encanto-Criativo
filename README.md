# Encanto Criativo 3.0

Gestão local de pedidos, custos, despesas, caixa e entregas para Windows com Node.js 24.

**Atualização:** extraia em uma pasta nova, preserve a instalação anterior e copie sua pasta `data` inteira antes de abrir os atalhos. Não reimporte os 43 pedidos.

Leia [o guia completo da versão 3.0](docs/VERSAO-3-WINDOWS.md). Depois execute `Atualizar-Dependencias.bat` e `Iniciar-Encanto.bat` na pasta nova.

O programa fica restrito a `http://127.0.0.1:3000`. Banco, anexos, planilha e documentos comerciais devem permanecer privados. A atualização não limpa nem importa dados automaticamente.

Base: branch `correcao-limpeza-colecoes`, commit `8c3d715`. Desenvolvimento: `versao-3-gestao`.
